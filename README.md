# cimos.github.io

Source for [CMOS Foundry](https://cimos.github.io) — Simon Maddison's site and blog.
Jekyll 4, built and deployed to GitHub Pages by GitHub Actions on every push to `master`.

```bash
bundle install
bundle exec jekyll serve --livereload   # http://localhost:4000
```

Codespaces: `bundle exec jekyll serve --livereload --host 0.0.0.0 --port 4000`.

See [`CLAUDE.md`](CLAUDE.md) for the repo layout, content how-tos, and design system,
and [`scripts/README.md`](scripts/README.md) for asset tooling.
